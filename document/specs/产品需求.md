## 1. 市场背景与定位

### 1.1 市场现状

2025-2026 年记账 App 市场核心变化：

- **用户放弃率 78%** — 能坚持记账半年的仅 23%。核心矛盾不是"功能不够"，而是"坚持太难"
- **自动化成为标配** — 语音记账、截图 OCR、通知栏自动抓取已是头部 App 的基础能力
- **AI 从"记录"到"决策"** — AI 不只做分类，开始做消费诊断、现金流预测、预算预警
- **隐私优先级上升** — 89% 用户偏好"数据不出设备"的设计，68% 用户关注安全认证
- **广告 = 流失** — 开屏广告是用户弃用的第一原因
- **用户画像** — 18-35 岁占 62%，峰值使用时段：午休 + 睡前

### 1.2 竞品定位

| App | 定位 | 核心优势 | 短板 |
|-----|------|---------|------|
| **一木记账** | AI 自动记账标杆 | 语音/截图/自动全免费，无广告，准确率 92%+ | 预算偏基础，跨端同步需手动 |
| **鲨鱼记账** | 极简手动 3 秒记 | 安装包 15MB，入口极短，用户 2860 万 | 有广告，分类粗，无 OCR |
| **随手记** | 深度财务管理 | 100+ 场景模板，家庭协作，专业报表 | 学习成本高，功能臃肿 |
| **钱迹** | 干净手工记账 | 无广告，无智能化，手动体验好 | 大干净，无 AI |
| **iCost** | 苹果生态资产管理 | 贷款利率，多币种，小组件好看 | 仅 iOS，小众 |
| **LedgerPro (我们)** | 开源极简记账 | 本地优先、安全（RSA+JWT）、纯记账无干扰 | 缺 AI/自动化，账户管理断裂 |

### 1.3 产品定位（调整后）

**LedgerPro = 开源、隐私优先的极简记账工具**

核心差异化：

- **开源透明** — 代码公开，数据格式开放，用户真正拥有自己的数据
- **隐私设计** — 本地优先存储，RSA 加密传输，可选择完全离线使用
- **纯记账无干扰** — 无广告、无理财推销、无社区，对标"钱迹"但比钱迹多一套同步能力
- **渐进式功能** — 不追求一木记账的全自动，但提供足够的效率工具让记账坚持下来

### 1.4 目标用户（不变）

大学生、职场新人、家庭财务管理者、自由职业者、极简主义者。以及**在意数据隐私的技术用户**。

## 2. 核心功能阵型（基于市场趋势重新排序）

### 第一梯队：坚持记账的驱动力（P0）

这些功能的共同目标是**降低记账心理门槛，让用户形成习惯**。

| 功能 | 市场验证 | 当前状态 |
|------|---------|----------|
| **3 秒快速记账** | 鲨鱼记账 2860 万用户验证"极简=留存" | ⚠️ 基础有，缺转账 |
| **语音记账** | 一木记账免费语音，用户核心诉求 | ❌ 未开始 |
| **AI 分类推荐** | 准确率 >90% 时续费率 +37 个百分点 | ❌ 未开始 |
| **桌面小组件** | 锁屏/桌面快捷记账，降低打开成本 | ❌ 未开始 |
| **预算进度提示** | 花钱时看到预算余额 = 改变消费行为 | ❌ 预算中心不存在 |
| **周期记账** | 房租/订阅自动生成，减少重复劳动 | ❌ 未开始 |

### 第二梯队：数据管理闭环（P1）

| 功能 | 市场验证 | 当前状态 |
|------|---------|----------|
| **多账户管理** | 88% 用户有 2+ 支付方式 | ❌ 账户管理断裂 |
| **转账** | 基础记账能力 1/3 | ❌ 缺 UI |
| **多账本** | 旅游/装修等场景账本 | ⚠️ 基础已有 |
| **交易搜索** | 翻列表找交易是高频场景 | ❌ 未开始 |
| **导入导出** | 数据自主权 | ✅ 已有 |

### 第三梯队：分析决策（P2）

| 功能 | 市场验证 | 当前状态 |
|------|---------|----------|
| **趋势图** | 月度收支趋势是最常看的报表 | ⚠️ 只有饼图 |
| **预算执行看板** | 预算 vs 实际 = 消费健康度 | ❌ 预算中心不存在 |
| **标签消费分析** | #报销 #旅行 等场景标签 | ❌ 未开始 |
| **商家排行榜** | "在 xx 花了多少钱"是常见问题 | ❌ 未开始 |

### 第四梯队：高级功能（P3）

共享账本/AA 结算、多币种、存钱目标、WebDAV 备份、应用锁 — 市场需要但非核心。

### 3.1 极速记账（主页 — 核心界面）

**视觉布局建议：**
```

│ [☰]    ‹ 7月 ›     [📊] │  ← NavBar（含月份+统计入口）

├─────────────────────────┤
│   🍔  🚌  🛒  🏠  🎬    │  ← 分类横向滑动
│         → 更多           │
├─────────────────────────┤
│      当前输入: 35        │
│   ┌───┬───┬───┐         │
│   │ 7 │ 8 │ 9 │         │
│   ├───┼───┼───┤         │
│   │ 4 │ 5 │ 6 │         │
│   ├───┼───┼───┤         │
│   │ 1 │ 2 │ 3 │         │
│   ├───┼───┼───┤         │
│   │C   0   . │ 保存     │  ← 数字键盘（绿色大保存按钮）
│   └───┴───┴───┘         │

└─────────────────────────┘
```

**需求要点：**

1. **类型 Tab** — 支出/收入
2. **统一现金记账** — 不区分账户、不选支付方式，记完即走
3. **智能分类推荐** — 基于时段（早餐→餐饮）、频率（上笔→同分类）、最近一周高频分类，高亮推荐
4. **备注** — 文本备注
5. **保存后动作** — 普通保存（关闭弹窗） / "保存并再记一笔"
6. **数字键盘** — 四则运算、小数点、退格（已有 ✅）

## 4. 数据模型变更

基于当前 DB，补充以下表：

```sql
-- 1. 预算表
CREATE TABLE budget (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    book_id BIGINT NOT NULL,
    user_id BIGINT NOT NULL,
    category_id BIGINT,          -- NULL = 总预算
    amount INT NOT NULL,         -- 预算金额(分)
    period_type TINYINT,         -- 0=月 1=周
    start_date DATE NOT NULL,
    carry_over TINYINT DEFAULT 0, -- 0=不结转 1=结转
    status TINYINT DEFAULT 1,    -- 0=暂停 1=活跃
    created_at DATETIME,
    updated_at DATETIME
);

-- 2. 记账模板表
CREATE TABLE transaction_template (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    book_id BIGINT NOT NULL,
    user_id BIGINT NOT NULL,
    name VARCHAR(50),
    type TINYINT,                -- 0=支出 1=收入 2=转账
    amount INT,
    account_id BIGINT,
    to_account_id BIGINT,
    category_id BIGINT,
    remark VARCHAR(200),
    sort_order INT,
    created_at DATETIME
);

-- 3. 标签表（如需热力图/报销场景）
CREATE TABLE tag (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    book_id BIGINT NOT NULL,
    name VARCHAR(30) NOT NULL,
    color VARCHAR(20),
    created_at DATETIME
);

CREATE TABLE transaction_tag (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    transaction_id BIGINT NOT NULL,
    tag_id BIGINT NOT NULL
);
```

## 7. 竞争策略：我们怎么做差异

| 维度 | 一木记账 | 鲨鱼记账 | LedgerPro |
|------|---------|---------|-----------|
| **开源** | ❌ | ❌ | ✅ **核心差异** |
| **隐私优先** | ❓ 云端同步 | ❌ 有广告商 | ✅ **数据不出设备** |
| **语音记账** | ✅ 免费 | ❌ 假的 | 🔲 规划中 |
| **自动记账** | ✅ 20 次免费 | ❌ | 🔲 远期 |
| **无广告** | ✅ | ❌ 有广告 | ✅ **天然优势** |
| **预算中心** | ⚠️ 偏基础 | ❌ | ❌ 已移除 |
| **WebDAV** | ✅ 付费 | ❌ | 🔲 远期 |
| **价格** | 订阅/买断 | 年费 119 | **免费+开源** |

**核心策略：**
- 不做一木的 AI 全面对标 — 那是烧钱路线
- **做好"开源版钱迹+同步"** — 手动记账体验打磨到极致 + 免费多端同步
- 轻量 AI（智能分类推荐 + 语音记账）在 v1.1 逐步加入
- 隐私和开源是护城河 — 竞品无法复制
