## 接口详细定义

### 1. 注册 — POST /api/v1/auth/register

**请求体：**
```json
{
  "email": "user@example.com",
  "password": "123456",
  "nickname": "用户昵称"
}
```

**响应：**
```json
{
  "code": 200,
  "message": "注册成功",
  "data": {
    "token": "eyJhbGciOiJI...",
    "userInfo": {
      "id": 1,
      "nickname": "用户昵称",
      "avatar": "",
      "email": "user@example.com",
      "phone": "",
      "role": "user"
    }
  }
}
```

**后端逻辑：**
- 校验 email 唯一性
- BCrypt 加密密码
- 插入 user 表
- 自动创建默认账本（名"日常账本"）+ 默认账户（"现金"）
- 生成 JWT 返回

### 10. 创建交易 — POST /api/v1/transactions

**请求头：** `Authorization: Bearer <token>`

**请求体：**
```json
{
  "book_id": 1,
  "type": 0,
  "amount": 2500,
  "account_id": 1,
  "to_account_id": null,
  "category_id": 1,
  "remark": "午餐",
  "trans_time": "2026-06-08T12:00:00"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| book_id | int | 是 | 账本 ID |
| type | int | 是 | 0-支出, 1-收入, 2-转账 |
| amount | int | 是 | 金额（分） |
| account_id | int | 是 | 源账户 ID |
| to_account_id | int | 否 | 目标账户 ID（转账必填） |
| category_id | int | 否 | 分类 ID（转账可空） |
| remark | string | 否 | 备注 |
| trans_time | string | 是 | 交易时间 |

**响应：**
```json
{
  "code": 200,
  "message": "记账成功",
  "data": {
    "id": 1,
    "book_id": 1,
    "type": 0,
    "amount": 2500,
    "account_id": 1,
    "category_id": 1,
    "remark": "午餐",
    "trans_time": "2026-06-08T12:00:00"
  }
}
```

### 11. 获取交易列表 — GET /api/v1/transactions?book_id=1&month=2026-06

**请求头：** `Authorization: Bearer <token>`

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| book_id | long | 是 | 账本 ID |
| month | string | 是 | 月份 YYYY-MM，查当月全量数据 |

**响应：**
```json
{
  "code": 200,
  "data": {
    "list": [
      {
        "id": 1,
        "book_id": 1,
        "type": 0,
        "amount": 2500,
        "account_id": 1,
        "category_id": 1,
        "remark": "午餐",
        "trans_time": "2026-06-08T12:00:00",
        "created_at": "2026-06-08T12:00:00"
      }
    ],
    "total": 1
  }
}
```

## 统一返回格式

所有接口遵循统一格式：

```json
{
  "code": 200,
  "message": "成功",
  "data": {}
}
```

| code | 含义 |
|------|------|
| 200 | 成功 |
| 400 | 参数错误 |
| 401 | 未登录 / Token 过期 |
| 403 | 无权限 |
| 500 | 服务端错误 |

## 实现顺序建议

| 优先级 | 接口 | 原因 |
|--------|------|------|
| P0 | Schema + 初始化数据 | 基础依赖 |
| P0 | 注册、登录 | 前端页面已对接 |
| P1 | 获取默认账本、分类列表、账户列表 | 前端记账页强依赖（目前 book_id/account_id 硬编码） |
| P1 | 创建交易、获取交易列表 | 核心记账闭环 |
| P2 | 获取用户信息 | 辅助功能 |
| P2 | 重置密码、发送验证码、刷新 Token | 一期可简化实现 |
