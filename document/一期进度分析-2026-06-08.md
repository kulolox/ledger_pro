## 代码问题清单

### 后端

1. **JWT 密钥不持久**: `Keys.secretKeyFor()` 每次启动随机生成，重启 token 失效。
2. **注册无重复校验**: `UserService.register()` 未检查 email 唯一性。
3. **分类/账户 API 缺失**: 前端仍用硬编码数据。
4. **无转账处理**: 后端 Transaction 模型有 toAccountId 字段，但无账户余额变动逻辑。
5. **测试仅空壳**: 无业务逻辑测试。

### 前端

1. **account_id 硬编码为 1**: TransactionEditor 新增时 account_id 写死。
2. **转账类型 UI 未实现**: typeTabs 仅有支出/收入，缺转账。
3. **分类颜色硬编码**: categories.ts 中 color 字段写死具体色值。
4. **分类/账户未从后端拉取**: 仍用前端本地 DEFAULT_CATEGORIES。
