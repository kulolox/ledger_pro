#### TransactionServiceImpl 实现

```java
@Override
public TransactionResponse update(Long id, TransactionRequest req) {
    Transaction tx = getById(id);
    if (tx == null) throw new BizException("交易不存在");
    validateBookOwnership(req.book_id());

    tx.setType(req.type());
    tx.setAmount(req.amount());
    tx.setAccountId(req.account_id());
    tx.setToAccountId(req.to_account_id());
    tx.setCategoryId(req.category_id());
    tx.setRemark(req.remark() != null ? SanitizeUtils.escapeHtml(req.remark()) : "");
    tx.setTransTime(LocalDateTime.parse(req.trans_time().replace(" ", "T")));
    tx.setUpdatedAt(LocalDateTime.now());
    updateById(tx);

    evictTransactionCache(req.book_id());
    return TransactionResponse.from(tx);
}
```

#### 前端 sync.ts 加推送逻辑

`pushPending` 方法中，编辑过的交易（`sync_status === "pending" && server_id` 存在）应调 `PUT /api/v1/transactions/{server_id}` 而非 `POST /batch`。

```typescript
// pushPending 中区分新增和更新
const newItems = pending.filter(t => !t.server_id);
const updateItems = pending.filter(t => t.server_id);

// 新增走 batch
if (newItems.length > 0) { ... POST /batch ... }

// 更新逐条走 PUT
for (const item of updateItems) {
  await request.put(`/api/v1/transactions/${item.server_id}`, { ... });
}
```

#### common.ts 加 API

export const updateTransaction = (id: number, data: {

**TransactionServiceImpl.list() 改造**

使用 MyBatis-Plus Page 分页：

```java
@Override
public TransactionListResponse list(Long bookId, String month, Integer page, Integer size) {
    validateBookOwnership(bookId);

    String cacheKey = AuthUtils.getCurrentUserId() + "::" + bookId + "::" + month + "::" + page;
    // 仍走缓存，key 含 page
    TransactionListResponse cached = cacheManager.getCache("transactions")?.get(cacheKey, TransactionListResponse.class);
    if (cached != null) return cached;

    LocalDate start = YearMonth.parse(month).atDay(1);
    LocalDate end = start.plusMonths(1);
    Page<Transaction> pageObj = new Page<>(page, size);
    var result = lambdaQuery()
        .eq(Transaction::getBookId, bookId)
        .eq(Transaction::getDeleted, 0)
        .between(Transaction::getTransTime, start.atStartOfDay(), end.atStartOfDay())
        .orderByDesc(Transaction::getTransTime)
        .page(pageObj);

    TransactionListResponse res = new TransactionListResponse(
        result.getRecords().stream().map(TransactionResponse::from).toList(),
        result.getTotal()
    );
    cacheManager.getCache("transactions")?.put(cacheKey, res);
    return res;
}
```

## 全局注意事项

### 金额单位

所有后端传输金额为 **分**（INT），前端展示时 ÷100。

### 归属校验

所有账本/账户操作必须：
1. 通过 `book.ownerId == currentUserId` 校验
2. 缺失校验 = 安全漏洞

### 同步兼容

- 新增 `PUT /transactions/{id}` 后，`sync.ts` 的 `pushPending` 需区分新增/更新
- 账户 CRUD 操作直接实时调用 API（本地改完即推），不用走离线 pending 队列（账户变更低频，不需要离线能力）

### 样式规范

- 使用 Wot UI 组件（wd-picker, wd-popup, wd-swipe-action 等）
- 转账金额蓝色（已有 `.transfer` 类）
- CSS 变量引用，不写硬编码色值
