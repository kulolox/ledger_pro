# 待完善功能清单

> 基于代码验证 + PRD v2 + 市场调研
> 更新日期：2026-07-23

---

## 已撤销（不再开发）

以下功能经评估后确认不在当前版本范围内：

| 功能 | 原因 |
|------|------|
| **转账** | 个人记账低频操作，增加 UI 复杂度 > 实际价值 |
| **账户管理页** | 默认 3 个账户（现金/支付宝/微信）满足绝大多数场景 |
| **预算中心** | 已移除 — 增加用户心理负担 |
| **趋势折线图** | 已移除 — 简化统计页 |
| **记账模板** | 砍掉 — 使用频率低 |
| **周期记账** | 砍掉 — 维护成本高 |
| **回收站 UI** | 砍掉 — 软删除足够，无需恢复入口 |
| **主题切换** | 砍掉 — 浅色主题已满足 |
| **应用锁** | 砍掉 — 平台依赖，小众需求 |
| **设置页** | 砍掉 — 无设置项需要暴露 |
| **加载态补全** | 砍掉 — 当前体验可接受 |
| **颜色变量化** | 砍掉 — 后续不再投入 |
| **分类智能推荐** | 砍掉 — 分类栏固定已够用 |
| **语音记账** | 砍掉 — 实现成本高 |
| **截图 OCR** | 砍掉 — 第三方依赖 |
| **标签系统** | 砍掉 — 过度设计 |
| **多币种** | 砍掉 — 目标用户无需 |
| **存钱目标** | 砍掉 — 心理负担 |
| **loadMore 分页** | 按月查不需要 |
| **共享账本/AA 结算** | 社交属性强但实现成本高 |
| **WebDAV 备份** | 小众需求 |
| **桌面小组件** | 平台适配成本高 |
| **自动记账（通知栏读取）** | 需无障碍权限 + 安卓厂商适配 |
| **私有云同步** | V2.0 路线，暂不投入 |
| **Siri/快捷指令** | 平台依赖 |

---

## 总结

项目功能冻结。当前版本即为最终版本，不再新增功能。
