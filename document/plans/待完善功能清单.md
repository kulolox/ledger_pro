## 观望清单（不投入）

以下功能市场有需求，但建议等数据库留存验证后再启动：

| 功能 | 理由 |
|------|------|
| 共享账本与 AA 结算 | 社交属性强但实现成本高，MVP 阶段不需要 |
| WebDAV 备份 | 目标用户群有需求但小众，云同步已有 |
| 桌面小组件 | 平台相关（iOS/Android），可作为 v1.5 亮点 |
| 自动记账（通知栏读取） | 需无障碍权限 + 安卓厂商适配，维护成本高 |
| 私有云同步 | V2.0 路线，付费功能 |
| Siri/快捷指令 | 平台依赖，用户基数够大后再做 |

## 已撤销需求

以下功能经评估后确认不在当前版本范围内：

| 功能 | 原因 |
|------|------|
| **转账** | 个人记账低频操作，增加 UI 复杂度 > 实际价值 |
| **账户管理页** | 默认 3 个账户（现金/支付宝/微信）满足绝大多数场景 |
| **预算中心** | 已移除 — 增加用户心理负担 |
| **loadMore 分页** | 首页按月查，不需要分页 |
| **共享账本/AA 结算** | 社交属性但成本高，等用户量验证 |
| **WebDAV 备份** | 小众需求 |
| **桌面小组件** | 平台适配成本高 |
